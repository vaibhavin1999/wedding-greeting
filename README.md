# Luxury Wedding Invitation

This is a Vercel-ready React + Vite wedding invitation.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this folder into Vercel. Vercel detects Vite automatically. The build command is `npm run build` and the output directory is `dist`.

## Replace the temple image

The hero reads the PNG at `public/temple.png`. Replace that file with any PNG artwork while keeping the same filename, or update the two `src="/temple.png"` references in `src/main.tsx`. No SVG conversion is required.
